# Agent Session Archiver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Collect original agent traces from configured hosts into an ordinary-file archive over SSH.

**Architecture:** Prepare stable source batches, transfer with rsync over SSH, and safely incorporate them on the archive host. Push and pull share those operations; only the initiating host differs. JSON manifests describe the archive without a database catalog.

**Tech Stack:** Go, system SSH, rsync, TOML configuration and JSON manifests. Optional sqlite3 CLI for database-backed harnesses only; no Go SQLite driver.

**Spec:** [Archive design](../specs/2026-11-01-archive-design.md)

## Global Constraints

- No sharding; user / host / project / harness / trace directories.
- Never propagate source deletions or overwrite an archived transcript with a shorter/conflicting source.
- No custom transfer protocol, inventory database, transaction journal, or authorization service.
- Listed harness tables enable collection; explicit directory lists replace native defaults.
- Multiple harness roots preserve provenance and cannot silently collide.
- All SSH connections originate on the initiating machine; no reverse connection is required.
- Linux and macOS; synthetic fixtures only in the public repository.
- Archive success and viewer import success are separate statuses.

## Review Focus

- Sanitized paths and native IDs collide across configured roots: keep traces distinct (Tasks 1–2).
- Remote ~ resolves under the wrong account: expand on the source, never the controller (Tasks 1 and 4).
- Source changes or disappears during capture: retain committed data and report partial failure (Tasks 2–3).
- Transfer fails or disk fills during incorporation: retry safely without requiring a transaction journal (Tasks 3–4).
- A database reset drops sessions: preserve older consistent snapshots (Task 5).

## Files and interfaces

Keep packages focused; introduce no speculative plugin framework.

- `internal/config/config.go`: `Load(path string) (Config, error)`. Config contains Archive, Hosts and Source; Host has SSH, User, Host and Harnesses; Source has User, Host and Harnesses. HarnessConfig holds optional Directories. Preserve absent versus explicitly empty lists.
- `internal/collect/collect.go` and `claude.go`, `codex.go`, `pi.go`, `evener.go`, `opencode.go`: `Prepare(ctx context.Context, source config.Source, batchDir string) (Report, error)`.
- `internal/archive/manifest.go`: versioned trace/source manifests, member sizes/hashes and provenance. No generalized shared-object graph.
- `internal/archive/store.go`: `Incorporate(ctx context.Context, archiveRoot, batchDir string) (Report, error)` and `Verify(ctx context.Context, archiveRoot string) (Report, error)`.
- `internal/remote/remote.go`: `Push(ctx context.Context, source config.Source, destination string) (Report, error)` and `Pull(ctx context.Context, host config.Host, archiveRoot string) (Report, error)`.
- `internal/report/report.go`: shared Report with discovered, transferred, incorporated counts and source-specific failures; aliases in interface descriptions refer to this type.
- `internal/cli/run.go`: `Run(ctx context.Context, args []string, stdin io.Reader, stdout, stderr io.Writer) int`; thin `cmd/agent-session-archiver/main.go`.
- Adjacent `*_test.go`, `tests/ssh_test.go`, `docs/operations.md`, `docs/archive-format.md`, and `.github/workflows/test.yml`.
